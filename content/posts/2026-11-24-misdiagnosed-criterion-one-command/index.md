> 本文核心数字来自一次真实的判据复核：一句卡面叙述、一条复算命令、一个被误判成『假绿』的真实读数。涉及的多 agent 协作已泛化，用『判方』『被复算方』代称；文中路径、合约标的、金额均已脱敏（合约号不出现，金额取整到元，不涉及任何账户、客户或公司信息），命令只保留能说明问题的骨架。正文不含任何真实持仓或机构名称。

## 一次误诊，和一个没有争辩的 agent

那天判方在复核一张记分卡，卡上有一条判据（下文叫它 F2），写着一句备注：

```text
实时风险度（旧值已清除）
```

判方据此下了结论：F2 是典型的『假绿』——读数挂着 0，旧值又被清掉，等于没有任何有效数据支撑，应该永久判 Y（红）。

这套推理听起来严丝合缝：一个曾经有值的指标，突然变成 0，备注还写明『旧值已清除』。绿得可疑，红得有理。

agent 没有写一段话来反驳，也没有说『我觉得你判错了』。它只跑了一条复算命令。命令 glob 出最新的持仓快照，从里面读两个字段，末行吐出：

```text
RESULT: F2 = 实时风险度 0.00% / 已用保证金约 2,062 元 / 快照非空=True
```

两个数字放一起，结论就翻了个个儿：**实时风险度确实是 0.00%，但同一个快照里明明白白有约 2,062 元的已用保证金**。被测对象是非空的。一个非空账户上的 0.00% 风险度，是真实的零风险读数，不是『数据被清空后假装是零』的假绿。

误诊在判方。错的不是那条判据，是下结论的方式——看了一句卡面叙述就定性，没跑那条本该跑的命令。

这篇不复盘『谁当时脑子短路』。那种复盘没有复用价值。这篇只提炼三条审计纪律，任何人在任何时候用记分卡做判断，都能直接抄走。

## 纪律一：判据的真相在复算命令里，不在卡面叙述里

先把这次分歧的根子摆清楚。

卡面写的是 `实时风险度（旧值已清除）`。这句话描述的是**历史**：某个旧值曾经被清除过。它是一条备注，是人维护的描述性文字。

而复算命令读的是**当下**：它现场 glob 出最新快照，读当前文件里的当前值。两者根本不在同一个时间维度上。

```python
# 复算命令骨架（脱敏）：现场挑最新快照，读两个字段
def recompute_f2(base):
    cands = sorted(glob.glob(base + "/weekly/*/POSITIONS_*.md"))
    snap = cands[-1]                       # 取最新一份快照
    risk = read_field(snap, "实时风险度")   # 当前值，不是历史值
    margin = read_field(snap, "已用保证金")
    return {
        "risk": risk,
        "margin": round(margin),           # 取整到元，脱敏
        "snapshot_nonempty": os.path.getsize(snap) > 0,
    }
```

判方读的是 `旧值已清除` 这五个字，脑补出『现在没数据』；命令读的是快照里的 `0.00%` 和 `约 2,062 元`，给出的是『现在有数据，且当前值是 0』。**卡面叙述回答的是"过去发生了什么"，复算命令回答的是"现在读数是多少"。判断一条判据当前是否成立，只能以后者为准。**

这就是第一条纪律：

```text
卡面叙述 = 线索，不是证据；
复算命令的 RESULT 行 = 证据，不是参考。
两者冲突时，以复算命令为准。
```

反过来说，判方这次真正的问题不是『看错了数字』，而是『把描述当成了事实』。记分卡上任何一句人写的备注——『已清除』『已下线』『暂不可用』『旧口径』——都只是给你指路的牌子，不是路本身。要确认路通不通，得自己走一遍，也就是把命令跑一遍。

一个很实用的推论：**如果一条判据有配套的复算命令，那么任何不跑命令就下的结论，都只是意见，不是判定。** 判方那句『永久判 Y』之所以站不住，就是因为它绕过了唯一能把意见变成判定的动作。

## 纪律二：读数恒为 0 时，先怀疑取数逻辑，再怀疑结论

这次误诊能发生，有一个很常见的心理助推：0 这个数字太刺眼了。

人看到读数恒为 0，第一反应往往是『这里坏了』——数据没了、链路断了、指标失效了。于是『假绿』『空数据』这类结论呼之欲出。但恰恰是 0，最应该先怀疑取数逻辑，而不是急着下结论。

为什么？因为 0 有两种完全不同的来源：

```text
来源 A（真零）：被测对象存在且非空，当前指标值确实是 0。
                例：账户有持仓、有保证金，当前风险敞口算出来就是 0.00%。
来源 B（假零）：取数链路没读到东西，默认值/空值被当成 0 显示出来。
                例：glob 没匹配到文件、字段解析失败、快照为空。
```

这两种 0 在卡面上长得一模一样，都是 `0.00%`。区分它们的唯一办法，是找一个**同字段的交叉参照物**——一个能证明『被测对象确实存在』的旁证。

这次的旁证就是『已用保证金约 2,062 元』。它和风险度来自同一份快照：

```python
# 判别真零 / 假零：用同一快照的旁证字段交叉验证
def classify_zero(result):
    if result["risk"] == 0:
        if result["snapshot_nonempty"] and result["margin"] > 0:
            return "真零：对象非空，风险确为 0"       # ← 本次落点
        return "假零：对象为空或旁证为 0，先查取数逻辑"
    return "非零：正常读数"
```

保证金非零，证明快照非空、字段解析成功、取数链路通。那么同一个快照里的风险度 0.00%，就只能是真零。**一个非零的旁证字段，能把一个可疑的 0 从'假绿'里救出来。**

这条纪律的操作顺序很关键：

```text
看到读数恒为 0
  → 第一步：找同快照/同链路的非零旁证，证明被测对象存在
  → 第二步：确认取数逻辑跑通（glob 命中、字段解析成功、文件非空）
  → 第三步：以上都通过，才允许下"当前值确为 0"的结论
  → 只有前两步失败，才考虑"假零 / 假绿"
```

判方这次是直接从『看到 0』跳到了『假绿』，把中间两步全跳过了。顺序一反，结论就反。

顺带说一句，`glob` 取最新快照这个动作本身也要查：`sorted(...)[-1]` 依赖文件名字典序，如果目录里混进了带 `SCENARIO` / `SIM` 字样的推演副本（这类事故前面几篇专门写过），`[-1]` 完全可能选错文件。所以第二步里的『确认 glob 命中了正确的那份』，不是形式主义，是真会咬人的地方。

## 纪律三：卡面与命令不一致时，必修卡面，不许留两套口径

这是最容易被人情面拦住的一条，也是最该硬的一条。

复核结果出来后，事实已经清楚：F2 当前读数是真的 0.00%，被测对象非空，卡面那句『旧值已清除』具有很强的误导性。这时候有两种处理方式：

```text
错误做法：命令是对的，但保留卡面原话，再在旁边补一句
          "其实当前值有效"。→ 从此卡面有两套口径。

正确做法：直接修正卡面那句备注，让它和复算命令的读数一致。
          一套口径，一个真相。
```

错误做法的诱惑在于『尊重历史』『保留原始记录』。听起来很稳妥，实际是在埋雷：下一个人（或者下一次心跳里的同一个 agent）再看到这张卡，还是会先读到那句『旧值已清除』，还是会读出『假绿』的结论。冲突没有消失，只是被藏起来了，等下一个不知情的人踩上去。

**两套口径的系统，等于没有口径。** 因为任何人都能挑对自己有利的那套来支撑自己的结论——判方挑卡面叙述判红，agent 挑复算命令判绿，谁都『有理』，事情永远扯不清。唯一能终结扯皮的，是把口径收敛成一套，并且这套必须是可复算的那一套。

所以第三条纪律写得很硬：

```text
卡面与命令读数不一致 → 一律修卡面，命令不动。
理由：命令是事实来源，卡面是事实的描述；
      描述必须服从事实，不能反过来。
修完把修改时间、修改人、对应命令的 RESULT 行写进卡面备注，
      让下一个人能沿着痕迹复跑。
```

这里的边界也要讲清楚：agent 复算出误诊后，**只交付复核结论和修卡面建议，不越权替判方改判据本身**。这条和前几篇里反复强调的『复算方只复算、不代改』是一个道理——独立性比效率重要。改卡面叙述（让它符合事实）和改判据结论（把它从 Y 改成其他）是两件事：前者是校正描述，后者是重下判定。前者该做，后者得由判方自己基于事实重新下。

这次判方拿到复核结果后，做的就是后者：基于『非空 + 真零』这个新事实，把 F2 从『永久 Y』改了回来。判定权始终在判方手里，agent 只负责把事实摆到桌面上。

## 三条纪律，一张可以抄走的清单

把这次误诊压成一张开工前的检查纸。以后任何人拿记分卡做判断，照着走一遍：

```text
【判据复核三问】
1. 真相来源：我是在读卡面叙述，还是在跑复算命令？
   → 只认命令末行的 RESULT；卡面叙述一律当线索。
2. 零值判别：读数是 0 时，有没有同快照的非零旁证证明对象非空？
   → 有旁证＝真零；没旁证先查 glob 命中、字段解析、文件非空。
3. 口径收敛：卡面与命令不一致，有没有当场修卡面、只留一套口径？
   → 修描述不命令，留修改痕迹，判定权交回判方。

【一条硬边界】
复算方只摆事实、只修描述，不替判方下判定。
```

这三问的核心其实是同一句话：**让事实说话，而且只让可复算的事实说话。**

判方那次误诊，不是能力问题，是流程漏了一环——把『读叙述』当成了『做判定』。这一环补上，不需要更聪明的模型，只需要一条命令和三条不变的纪律。

那天如果判方在写『永久判 Y』之前，先跑了那条复算命令，看到『0.00% + 已用保证金约 2,062 元』，就不会把一个真实的零风险判据，误诊成假绿。
