> 写给同辈的一句话：爸妈家里那几盒「几千块买的保健品」，往往是从一句「免费领鸡蛋」开始的。骗子不怕你不买，就怕你不来——只要你来领第一次，后面每一步都有人替你安排好。这篇不劝爸妈「别贪小便宜」（这话说了没用），只拆穿套路，再给你和爸妈几个当场能做的动作。

## 结论先放前面

记住三条，别的都是解释：

1. **凡是「先免费送、后面让你掏钱」的，掉头就走。** 免费的鸡蛋、面条、洗洁精，成本几毛钱，换的是你的手机号、你的信任、和一次到场的机会。它从来不是白送。
2. **凡是「在群里通知、私聊下单、不许告诉子女」的，先打给子女。** 正经生意不怕家人知道；越不让说，越有问题。
3. **凡是「讲课+现场逼单+今天不买就没了」的，一律不当场付钱。** 把东西拍个照、把话术记下来，回家商量。真的好，明天还在；不让你回去想的，一定是假的。

下面一节一条，讲清楚套路怎么走、爸妈为什么会中、以及你当场该怎么做。

## 一、这套路是四步走，每一步都踩在爸妈的软肋上

### 第 1 步：免费送，先把人聚起来

小区门口、公园、超市旁边摆个摊，拉个横幅写着「关爱老人，免费领鸡蛋」「扫码入群送礼品」。不要钱，扫个码、留个手机号、加个微信就能领。

几毛钱一枚的鸡蛋，换来的是三样东西：

- **你的手机号和微信**——从此他们能直接联系到你。
- **你「这个人靠谱」的第一印象**——拿了人家的东西，多少有点不好意思不给面子。
- **一次到场的机会**——下次「免费听健康讲座、还送礼品」，你就更可能去。

这一步不图赚钱，图的是**把你从陌生人变成「认识的人」**。

### 第 2 步：建群 + 日常关怀，比亲人还勤快

进了群，画风一下变了。群里有「小老师」每天早早安、晚上问好，天气变了提醒添衣，过节发祝福，比子女还殷勤。时不时发个红包、分享个「养生小知识」，再私聊问一句「阿姨最近身体还好吧」。

这一步图的是**情绪价值**。很多爸妈子女在外地，日常缺的就是这份被惦记的感觉。等这份信任攒够了，后面卖什么，他都愿意听。

### 第 3 步：讲座洗脑，把普通东西说成「神药」

群里的「专家讲座」开讲，通常三板斧：

- **吓你**：把你身上的小毛病说得很重，「你这血压再不管就要出大事」「血糖高就是糖尿病前期」。
- **抬价**：把产品说得神乎其神，「天文数字的研究投入」「某院士团队研发」「一粒顶三副药」——这些话你细想全是空话，但在现场的氛围里，老人很难细想。
- **造势**：安排几个「托儿」现场现身说法，「我吃了三个月，腿脚利索多了」「我老伴的毛病就是吃这个好的」。

讲完课，再看那盒东西的包装——**很多就是普通的保健食品，甚至只是普通食品**，成本几十块，标价几千块。

### 第 4 步：限时逼单，让你来不及想

最后一步最关键，也最阴：

- 「今天现场订购，买三送一，明天就恢复原价。」
- 「这个月只有 20 个名额，现在不订就没了。」
- 「阿姨你先交个定金，我帮你留一个。」

**为什么非要逼你当场掏钱？** 因为只要你回家想一晚、跟子女商量一句，这单多半就黄了。他们要的就是你**没时间核实、没机会商量**的那几分钟。

## 二、为什么偏偏是爸妈中招

先说清楚：**这不是因为爸妈贪、笨、或没文化。** 很多退休老师、老工程师一样中招。骗子踩的是三个几乎人人都有的心理缺口：

- **怕病、怕拖累子女。** 一句「你这毛病不管会出大事」，比任何话术都好使。老人买的不是保健品，是「不给孩子添麻烦」的安心。
- **人情债的心理。** 拿了人家几个月的鸡蛋、天天问候，「不买点什么不好意思」——这份不好意思，就是被精心养出来的。
- **群里人都「这么干」的从众压力。** 现场一堆人抢着订货，你一个人不买，反而显得「不合群、不关心自己身体」。

看懂这三点，你就不会再去怪爸妈「怎么这么傻」。**他们不是在跟骗子斗智，是在跟自己的孤独和恐惧打交道。** 所以劝的方式也得换：别骂「你被骗了」，要说「这东西咱先放放，我陪你查查」。

## 三、一张识别表：他说的话 → 想干嘛 → 你该怎么回

| 他说的 / 做的 | 背后想干什么 | 你（或爸妈）该怎么回 |
|---|---|---|
| 「扫码入群免费领鸡蛋」 | 拿手机号、加微信、建信任 | 领可以，但不扫陌生码、不留真实姓名；最好别去 |
| 群里每天问早安、发红包 | 养信任、补情感缺口 | 客套可以，凡是提到钱立刻警觉 |
| 「阿姨你血压高，不管会出大事」 | 用恐惧打开钱包 | 「我有医保、有医生，体检报告说了算」 |
| 「院士团队研发，一粒顶三副药」 | 把普通货吹成神药 | 「有批号吗？我在药监局官网查一下」 |
| 现场一群人抢着订 | 制造从众压力 | 「别人买不表示靠谱，我先回家想想」 |
| 「今天不订就没了 / 只剩 20 个名额」 | 逼你没时间核实 | **越催越不买**，明天还在才是真的 |
| 「别告诉你孩子，说了他们不让买」 | 切断你的核实渠道 | **越不让说越要说**，当场打给子女 |

一句话记法：**免费是钩子，关怀是饵，讲座是刀，逼单是收网。**

## 四、四个当场能做的动作

### 动作一：凡是「先免费后掏钱」，掉头就走

给爸妈立一条最简单的规矩：**免费的东西可以拿，但只要对方开始讲产品、让你掏钱，立刻走人。** 不解释、不听「再坐一会」、不接对方递过来的样品。

走不掉就一句话挡回去：「我没带钱，改天再说。」然后走。

### 动作二：凡是「群里下单 / 私聊转账 / 不让告诉子女」，先打给子女

跟爸妈约好：**任何超过一顿饭钱的花费，先在群里问一句子女。** 不用讲道理，就一句「我给孩子打个电话确认一下」。

- 正经卖家听到这句会说「您问吧」；
- 骗子听到这句会急、会拦、会说「不用问」——**这就是最好的照妖镜**。

### 动作三：查三样——批号、价格、资质

子女帮忙核实时，不看宣传单，查三样：

1. **批号**：保健食品看包装上有没有「蓝帽子」标志和批准文号，去官方平台查得到才算数；普通食品根本没有保健功能，包装上敢写「治疗」「降三高」就是违规。
2. **价格**：同样的东西，网上搜一下品牌名+规格，价格差几倍甚至几十倍，基本就清楚了。
3. **资质**：卖的人是谁、有没有实体店、能不能开发票。群里一个昵称、一个私聊收款码，什么都不留——这不叫生意。

```text
三查口诀：
查批号 —— 有没有「蓝帽子」？官方平台查不查得到？
查价格 —— 网上同款多少钱？差几倍就是几倍的坑。
查资质 —— 谁在卖？能不能开票？只有一个收款码的，不买。
```

### 动作四：给家里立一条「金额线」

把规矩定死、写下来，别靠记性：**单笔超过一个商量好的金额（比如一顿饭钱、或家里约定的一个数），必须先跟子女说一声。** 不管买什么、不管谁催、不管什么「名额」。

这条线的意义在于：它把「要不要买」这个需要临场判断的难题，变成了「超过这个数就打电话」这个不用动脑的机械动作。**老人不需要在骗子面前保持清醒，只需要记得一条机械规则。**

## 五、把动作串成一条流程

接到讲座邀请、看到群里的订货通知，按这个顺序走，哪一步过不了就停：

```text
收到「免费领 / 听讲座 / 群里订货」的邀请
        │
        ├─ 第 1 步：要不要掏钱？
        │        ├─ 一提产品、一提钱 → 掉头走，停
        │        └─ 纯免费、不掏钱 → 继续看下一步
        │
        ├─ 第 2 步：是不是群里 / 私聊下单？
        │        ├─ 是 → 先打给子女，停
        │        └─ 不是 → 继续
        │
        ├─ 第 3 步：现场有没有人催「今天不买就没了」？
        │        ├─ 有 → 越催越不买，停
        │        └─ 没有 → 继续
        │
        └─ 第 4 步：查批号 / 查价格 / 查资质
                 ├─ 任一查不过 → 不买，停
                 └─ 三项都过、还要等子女点头 → 才谈买

记住：能让你回家想一晚的，才是真的；不让你想的，一定是假的。
```

## 六、已经进群、已经买了，怎么补救

别骂、别急，按顺序做：

1. **先止损，不再追加。** 那句「再买一个疗程才见效」是二次收割，一分钱都别再掏。
2. **保留证据。** 产品包装、付款记录、聊天记录、群消息、讲座宣传单，全部留着，一条别删。
3. **查是不是「三无」。** 用第四节动作三查批号、价格、资质。确认是普通食品冒充保健品、或价格离谱的，这就是维权的关键证据。
4. **能退就退。** 通过原付款渠道申请退款；实体店买的，带包装和票据去退。对方不退，走第 5 步。
5. **该举报就举报。** 涉及虚假宣传、无资质经营、金额较大的，拨 12315（市场监管）或 110；在微信里被骗的，用微信的投诉入口举报那个账号和群。
6. **退群、拉黑、告诉家里其他人。** 骗子手里有爸妈的手机号和家庭信息，很可能换个人接着骗。全家都提个醒。

**最要紧的一句：别怪爸妈。** 骂一顿的结果，往往是他们下次瞒着你买。把规矩立好、把查证的路子教给他们，比事后翻旧账有用得多。

## 七、给爸妈的一张纸

下面这段可以直接打印，或者截图设成手机壁纸，贴在电话机、药盒子旁边都行。

```text
【有人让你「免费领」「听讲座」「群里订货」，记住这几条】

2 群里下单、私聊转账、不让告诉孩子的，先打给子女。
   越不让说，越有问题。

   真的好东西，明天还在。
4 买之前查三样：查批号（蓝帽子）、查价格（网上同款）、
   查资质（谁在卖、能不能开票）。

【立一条家里的规矩】
单笔超过一个约定的数，必须先跟子女说一声，
不管买什么、不管谁催、不管什么名额。

【记住三句】

· 讲课 + 逼单 = 不让你想，不让你想的就是假的。
· 拿不准就打给孩子，正经生意不怕人知道。
```

## 八、几种拿不准的情况

- **真想买点保健品，怎么买才稳？** 去正规药店、医院或大型平台，认准「蓝帽子」和批准文号，看清楚它是「保健食品」还是「普通食品」——后者不许宣传任何治疗、保健功能。最好让子女一起挑。
- **爸妈已经加了群，退不掉怎么办？** 先设置「消息免打扰」，再退群；退不了就举报+拉黑。同时把那个「小老师」的微信删了，断掉私聊渠道。
- **对方说「是国家政策/社区搞的福利」** → 一律去社区居委会、街道办**当面核实**，别信群里的截图和链接。真有这好事，官网和社区公告查得到。
- **爸妈说「我自己的钱，我作主」** → 别硬顶。顺着说「对，你作主，就是让孩子帮你参谋一下」，把第四节那条「金额线」立起来就够了。目标是止损，不是吵赢。
- **已经付了大额、对方拉黑失联** → 直接跳第六节第 5 步，保留证据拨 110，越快越好。
