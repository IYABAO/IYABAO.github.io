> 写给同辈的一句话：这年头骗子不只会打电话冒充，还会**克隆你孩子的声音、换上你孩子的脸**，在手机那头甜甜地叫你一声「妈」，你根本分不出真假。不用慌，有一个特别简单的办法：**给家里人设一个只有你们才知道的暗号**。问一句，答对了是自己的娃；答不上来，直接挂电话。

## 结论先放前面

先说清楚：**AI 换脸和拟声诈骗，不是电影里的高科技，已经就在身边了。** 骗子拿到一段家人几秒钟的语音或视频，用专门的工具就能复制出一个「模仿版」——声音几乎一模一样，脸也能在视频里动。上一代骗子靠话术骗人，这一代骗子连声音和长相都能造假，长辈更防不住。

但破解的办法一点都不高科技，反而特别土、特别有效：**设一个家里独有的暗号。**

三句话先记住，后面都是展开：

- **凡是电话里要钱、要验证码、说急事的「亲人」，先对暗号，对不上就是假的。**
- **暗号要一问一答、不给外人看、别写在手机备忘录里。**
- **万一真转了钱，别慌别瞒，第一时间打 110，再联系银行，把证据留好。**

这篇接着前几篇《教爸妈守好验证码》《教爸妈只背三个数防骚扰》《教爸妈把骚扰电话拦下来》往下写，专讲「听起来像亲人、看起来像亲人」的骗局怎么破。口语、步骤化，不吓人不绕弯，每节附「千万别做」清单。

## 一、三种最常见的冒充场景，先认出来

骗子要钱，前提是让长辈信「这是我孩子 / 这是我老伴」。跟以往纯打电话不同，现在他们会用**假声音、假脸**增加可信度。最常见的三种：

### 场景一：微信 / QQ 语音求助转账

- 骗子克隆了孩子的语音，发来一条「妈，我这边急用钱，先转我五万，回头给你」的语音。
- 或者打语音电话，冒充孩子，声音几乎分不出真假。
- 特征：**特别急，催着马上转，还叮嘱「先别告诉我爸 / 先别声张」。**

### 场景二：视频通话要验证码

- 骗子用 AI 换上孩子的脸，跟你视频，屏幕里那张脸说话、眨眼都正常。
- 聊几句后就说「哎我手机丢了，刚收到个验证码，你帮我念一下」。
- 特征：**视频时间短、画面稍微有点卡或模糊**（假脸渲染有破绽），重点永远是「验证码」。

### 场景三：冒充子女说「手机丢了」

- 电话里带着哭腔：「妈，我手机被偷了，现在重启不了，微信也上不去，你先帮我交个话费 / 转笔钱救急。」
- 特征：**新号码、催得急、不让你挂电话、不让你打原来的手机号核实**。

这三种的共同套路就一个：**利用「孩子出事、爸妈心慌」的瞬间，不给你冷静核实的空档。**

## 二、家庭暗号怎么设（最重要的技能）

这是整篇的核心。暗号就是**你和你家人之间一句只有你们懂的问答**，比任何反诈软件都管用，因为骗子无论如何都猜不到。

### 怎么设：一问一答，越家常越好

- **一问一答**：一个人问一个只有本人才知道答案的问题，例如——你：「你生日几号？说全了。」儿：「十一月八号。」
- **越家常越好，别用网上能查到的**：别用生日、住址这种，骗子可能从你朋友圈、家庭群聊天里拼出来。用一件外人根本不知道的小事：比如「咱家那只猫叫什么名字」「你小时候摔破膝盖在哪家医院缝的针」。
- **可以设好几个**，按场合用（问钱的用一个、核对信息的用另一个）。

### 怎么守，三条红线

1. **暗号只用嘴说、记在脑子里**，别写进手机备忘录、别设成短信放通讯录——手机一丢或手机中病毒，暗号就跟着泄了。
2. **只告诉最亲近的家里人**，不给外人、不给亲戚群里的人，就是「只有家人知道」的意思。
3. **让家里每个人都复述一遍自己的回答**，别只有爸妈知道，孩子也得会答。全家约好：**只要在电话 / 视频里涉及「要钱、要验证码、报账号、放门口东西」，一律先对暗号。**

### 一句话记住

> 电话或视频里，对方只要开口提「钱 / 验证码 / 账号」，你的第一反应不是发火，也不是照着办，而是平静地来一句：**「你先对个暗号，上周我们说好的那个。」** 对得上，是自己人，接着办；对不上，直接挂断，一个字都别再说。

## 三、已经转了钱，第一小时该做什么

万一真中招、钱已经转了，**别慌、别瞒、别自责**——自责和害怕解决不了问题，第一时间做对这几件事，钱可能还追得回来。记顺序：

1. **立刻打 110 报警。** 讲清楚：什么时候、通过什么方式、转给谁、转了多少。警方要赶在骗子把钱转走前冻结。
2. **马上联系银行**（银行客服或直接去柜台），申请止付 / 冻结这笔转账。银行有办法在到账前拦截，所以动作越快越好。
3. **保留所有证据**：转账记录、聊天记录、通话记录、对方账号截图，一个都别删。这些是警方立案和追款的关键。
4. **告诉家里人**，让全家都警惕——骗子很可能拿到你手机里存的家人信息，继续去骗家里其他人。

### 冰冻三尺非一日之寒，也要防在平时

- **别在手机里存「爸爸 / 妈妈 / 儿子」这种实名备注**，改用家人小名或不带身份的名字，手机丢了骗子就不容易立刻锁定目标。
- **视频 / 语音要少发带脸带声的长片段**给陌生人（比如群里的公开场合），那是给骗子送「造假素材」。
- 家人生病或出远门期间，最容易被顶上来冒充，那段时间多留个心眼。

## 四、给子女的一张纸

下面这个口诀，你可以**直接打印出来，贴在爸妈手机旁边**，或者存成一张图设成聊天背景。

```text
【接电话 / 接视频前，先想这句】

一听对方要钱、要验证码、要账号——
先别慌，先对暗号，对不上就挂。

【家庭暗号】
问：____（比如：咱家那只猫叫什么名字）
答：____（答案只有家里人知道）

【已经转了钱，第一小时】
1 打 110
2 联系银行，申请止付
3 截图留证据，别删
4 告诉家里所有人

【平时】
- 手机备注别存「爸爸 / 妈妈」
- 别给陌生人发带脸带声的长视频
- 家人出远门，多留个心眼
```

## 五、出错怎么办（补救一条路）

- **对完暗号发现对不上，但已经在转钱了** → 立刻停手，别把钱转出去，然后按「第一小时」步骤走。
- **暗号不小心泄出去了**（比如随口跟人提过）→ 当场换一个全新的问答，别再用旧的。
- **不小心点开了骗子发来的链接 / 视频** → 别乱点第二个链接，退出，杀毒，必要时到线下营业厅让工作人员帮忙看。
- **心里存疑、拿不准是不是孩子** → 用你自己手机里存的、**和对方完全不同的**号码打过去核实一次，别用那段视频里的号码回拨。
