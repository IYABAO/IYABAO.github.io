> 写给同辈的一句话：你妈接到的那个电话，声音确实是你——只是那不是你。现在克隆一段声音只要几秒钟素材，视频里的脸也能换。好消息是，这些假东西有个共同死穴：**它经不住「挂断、回拨、让对方现场做个动作」这三下**。这篇就把这三下写成爸妈能照着做的步骤。

## 结论先放前面

先记住三个动作，别的都是解释：

1. **挂断，然后用你自己通讯录里的号码打回去。** 别用刚才那个来电的号码回拨——那个号是骗子控制的。用你手机里存的、平时打惯的那个号，打不通、或者接起来的人一头雾水，就是假的。
2. **对家庭暗号。** 一句只有家里人知道的问答，问出口，答不上来直接挂。
3. **让对方做一个「临时指定」的动作。** 比如用手把脸整个挡住再放下、慢慢转头、说一件只有家里人才知道的旧事。骗子手里的素材是「录好的」和「提前生成的」，你临时点的这道题，他现做不出来。

这三条不是「理论上管用」，是**当场能做完的**。下面一节一条，讲清楚怎么做、为什么管用、骗子会怎么绕。

## 一、先认清楚：现在的冒充能「像」到什么程度

不用懂技术，但得知道骗子的成本降到什么程度了，不然你会觉得「我儿的声音我不可能听错」。

- **声音**：几秒钟的语音素材（家庭群里发过的语音条、短视频里的一句话）就够克隆。克隆出来的声音能带语气、能带口头禅，甚至能哭。
- **脸**：一段十几秒的视频就能换脸。视频通话里那张脸会说话、会眨眼，但**多半有点僵、有点糊、动作对不上话**。
- **剧本**：永远是老三样——出事了、急着要钱、别告诉别人。「妈我撞人了要赔钱」「我手机丢了这是我新号」「别跟我爸说」。

所以别再指望「我听得出我儿子的声音」。**要靠流程，不靠耳朵。**

## 二、三个可当场做的核验动作

### 动作一：挂断，用你自己通讯录里的号码回拨

这是最硬的一条，也是最多人做错的一条。

**做错的版本**：骗子说「妈我手机丢了，这个是借的号」，你挂了电话，接着**按刚才那个来电号码拨回去**——那头当然还是骗子。

**做对的版本**：

1. 挂断。不用解释，直接说「我这边有点事，等一下打给你」然后挂。
2. 打开手机通讯录，找到你**自己存的那个号**（存的是「儿子」「闺女」还是小名无所谓，关键是你自己存的）。
3. 拨出去。
4. 三种结果，判断很干脆：

| 回拨结果 | 说明什么 | 怎么办 |
|---|---|---|
| 通了，对方说没给你打过电话、也没事 | **刚才那个是假的** | 挂掉，拉黑原号码，告诉家里人 |
| 通了，对方说确实是他、确实在要钱 | 可能是真的，但**别在这通电话里转账** | 换成当面、或者让另一个家人再确认一次 |
| 打不通 / 关机 / 一直没人接 | **当成假的处理**，宁可不转 | 等联系上本人再说，急事不差这十分钟 |

**为什么这条最硬**：骗子能造假声音、造假脸，但造不出「你手机里存的那个号码能接通本人」这件事。他控制的是他手里那张 SIM 卡，不是你通讯录里那条记录。

**两个注意**：

- **通讯录备注别写「儿子」「女儿」这种词**，改成小名或者名字缩写。手机丢了、被顺走，骗子翻开通讯录就知道该冒充谁。
- 回拨之前**别在原来那通电话里说太多**——你说得越多，他手里的克隆素材越多。

### 动作二：对家庭暗号

暗号这件事前面那篇《教爸妈识别 AI 换脸与拟声诈骗》已经讲过，这里只补**这次的用法**，因为「冒充家人要钱」这个场景下，暗号有讲究。

**怎么设**（十分钟能定完）：

- **一问一答**，答案必须是外人查不到的。别用生日、别用住址、别用「我属什么」——这些朋友圈和家庭群都能翻出来。
- 用「只有你们一起经历过」的小事：小时候在哪家医院缝的针、老家院子里那棵树是谁种的、某年春节在谁家吃的饭。
- **每个家人一个专属问题**，不共用。共用的问题，一个人说漏了，全家都失守。
- 定完让每个人**当面复述一遍**，包括孩子。只有爸妈会答、孩子答不上来，等于没设。

**怎么用**：

> 对方一提钱、一提验证码、一提账号，你就平静地说一句：**「你先答个问题。」** 问出来，他答对了再谈事；答不上来、绕、说「妈你都忘了」「这时候你还考我」，**直接挂**。

**骗子最常见的两种绕法**：

- **卖惨施压**：「妈我都这样了你还考我？」——记住，真的是你孩子，会答；越催你、越不让你核实的，越可疑。
- **假装信号不好**：「喂？喂？听不清」然后挂掉，换号再打。这叫**打断你的核验节奏**，你就当他是假的，重新走动作一。

**暗号泄了怎么办**：跟人随口提过、写在了手机备忘录里、发过微信——**当场换一个新的**，别心疼。

### 动作三：让对方做一个「临时指定」的动作

这一条是专门对付视频换脸的。声音能克隆，脸能换，但**换脸是「实时渲染」**，你临时点的动作，它跟不上。

**你可以让他做的**（挑一两样就够）：

- **用手掌把整张脸挡住，停两秒，再放下。** 换脸模型最怕遮挡和快速移动，手一挡一放，边缘会糊、会漂、会闪一下。
- **慢慢转头，从正面转到侧面。** 侧面是最难伪造的角度，很多假脸一到侧脸就崩。
- **用手指在脸前面晃一下。** 假脸的手指经常是糊的、和脸粘在一起。
- **说一件只有家里人才知道的旧事**：「你说说，去年你带我去的那家馆子叫什么？」「你小时候被狗追是哪一年？」——**这种题他提前准备不了**，因为他不知道你会问哪一件。

**为什么管用**：骗子的素材是**提前准备好的**——一段录音、一段换脸视频、或者一套跟着他说话的实时模型。你临时出题，等于逼他「现场创作」，而他现场创作不出来。

**注意两点**：

- **别提前把「要问什么」告诉任何人**，包括在家庭群里讨论。这道题的价值就在于它是临时的。
- **对方做了但还是不对劲**（画面卡、声音延迟、动作僵硬）→ 别纠结，**走动作一，回拨**。判断不了就用最硬的那条。

## 三、三个动作怎么串起来用

不用每次都做完三个，按这个顺序走，哪一步过不了就停：

```text
接到「家人」来电 / 视频，对方提钱、提验证码、提账号
        │
        ├─ 第 1 步：先挂断（说「等一下我打给你」）
        │
        ├─ 第 2 步：用自己通讯录里的号码回拨
        │        ├─ 通不了 / 对方说没打 → 假，停
        │        └─ 通了、确实是本人 → 还要再确认一句
        │
        ├─ 第 3 步：问家庭暗号（答不上来 → 假，停）
        │
        └─ 第 4 步：视频里让他挡脸再放下 / 说一件家里的旧事
                 └─ 做不出来、做得别扭 → 假，停

四步全过，才谈钱。
```

一句话版本，可以背下来：**挂断 → 回拨 → 对暗号 → 让他做个动作。**

## 四、骗子会怎么反制（提前打好预防针）

知道他会怎么绕，才不会被绕过去。

| 骗子的话术 | 他想干什么 | 你该怎么回 |
|---|---|---|
| 「妈我手机丢了，就用这个号」 | 堵死你「回拨原号」的路 | 用**你自己通讯录里**的号回拨，不是他给的号 |
| 「你别告诉我爸 / 别跟别人说」 | 切断你的外部核实渠道 | 越不让说越要说，先打给另一个家人 |
| 「我这边信号不好，你快点」 | 不给你冷静的时间 | 慢下来反而是对的，急事不差三分钟 |
| 「这时候你还考我？妈你是不是不信我」 | 用情感压力跳过核验 | 真的是自己孩子，答得出来 |
| 视频里「露个脸」但只露几秒、角度固定 | 用预录素材糊弄 | 让他挡脸、转头、晃手，做不出来就是假的 |

还有一类更阴的：**骗子先冒充「警察」「银行」「客服」打给你，说你家孩子出事了**，然后「帮」你转接给「孩子」。这种一律按上面的流程走——**你打出去的电话才算数，别人转进来的都不算。**

## 五、万一钱已经转出去了，第一小时

别自责，自责不解决钱的问题。按顺序做：

1. **打 110 报警**。说清楚时间、方式、对方账号、金额。越早，冻结的可能越大。
2. **联系银行**（客服或柜台），申请止付 / 冻结这笔转账。
3. **把所有证据留住**：转账记录、聊天记录、通话记录、对方账号截图。一条都别删。
4. **告诉家里人**，特别是刚才被冒充的那位——骗子手里可能还有更多家庭信息，会接着骗别人。
5. **别信「能帮你追回钱」的二次诈骗**。报警之后有人主动联系你说能追款、要你先交手续费的，全是假的。

## 六、给爸妈的一张纸

下面这段可以直接打印，或者截图设成手机壁纸。贴在电话机旁边也行。

```text
【有人打电话 / 视频跟你要钱，先做四件事】

1 挂断。说一句「等一下我打给你」，然后挂。
2 回拨。用你自己手机通讯录里存的那个号打回去。
   —— 别用他打过来的号！
3 对暗号。问那个只有家里人才知道答案的问题。
4 让他做动作。视频里让他用手挡住脸再放下、
   慢慢转头、说一件只有家里人知道的旧事。

四件事有一件不对，就是假的。挂掉，拉黑，告诉家里人。

【记住三句】
· 声音像、脸像，都不算数，流程才算数。
· 越催你、越不让你核实的，越可疑。
· 通讯录里别写「儿子」「女儿」，写小名。
```

## 七、几种拿不准的情况

- **回拨通了，但他说话也别扭** → 可能是真的本人在被人指使，也可能是骗子用了呼叫转移。**换成当面见，或者让另一个家人再打一次。**
- **老人不会用「回拨」** → 提前在他手机通讯录里把家人的号**置顶**，教一句「点这个名字就能打」。这一步值得花十分钟当面教。
- **对方是微信语音 / 视频，不是电话** → 一样，先用**手机号**打过去核实，别在微信里继续聊。
- **暗号对方答得含糊**（说「就那个嘛」「你忘了？」）→ **算答不上来**，当假的处理。
- **已经把钱转了才想起来核验** → 直接跳第五节，别再跟对方联系。
