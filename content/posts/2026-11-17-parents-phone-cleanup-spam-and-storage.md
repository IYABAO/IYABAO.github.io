> 写给同辈的一句话：教爸妈清手机，别一上来就教他「设置」在哪。先帮他挡掉骚扰、认出陷阱，再腾空间——**看不懂的短信一律别点，陌生号码打进来别回，存储满了先删缓存别删照片**。顺序对了，手机清净了，钱也不会被骗走。

## 结论先放前面

前阵子回趟家，我爸的手机卡得连微信都打不开。他以为手机「老了、该换了」，我拿过来一看，存储只剩几百兆，短信箱里塞了两百多条没读的营销短信，最近还点开过一条「补贴领取」的链接，吓出一身汗——幸好没让他填任何东西。

清理这件事，对年轻人是「手机卡了清一清」，对长辈是三道坎，一道比一道贵：

1. **认不出垃圾短信**，点开链接、照着填，钱就没了。
2. **不会开骚扰拦截**，一天接七八个推销电话，还以为是自己名声在外。
3. **不敢删东西**，存储满了就一直卡着，或者被人忽悠「一键清理」把照片清没了。

这篇接着上一篇《教爸妈清相册、换新机搬照片》往下写，专讲这三件事。不讲参数、不堆术语，给一套能照着做的顺序，每步一句大白话，中间夹「千万别点」清单，最后附一张纸，你可以直接打印出来贴在爸妈手机旁边。

三句话先记住，后面都是展开：

- **短信里让你点链接、报验证码、先交钱的，一律不点、不给、不回。**
- **骚扰拦截一次设好，能清净好几个月，不用天天跟推销电话纠缠。**
- **存储满了先删缓存和没用的软件，照片和微信聊天记录最后动、慢慢动。**

## 一、认垃圾短信：先看三样，再决定点不点

长辈最容易吃亏的地方，是「把短信当熟人说话」——短信躺在收件箱里，看着跟银行通知、快递提醒一模一样，就顺手点了。教他一个笨办法：**任何短信，先按这三看扫一遍，三样里有一样不对，手指就收回来。**

### 第一看：谁发的

正规机构（银行、运营商、快递、医院）的短信，落款是一个固定的名字，不会是一串陌生手机号，也不会是「某某服务中心」这种含糊的称呼。

- 发信号码是**一长串陌生数字**、看着就像随手编的，先当成可疑。
- 落款写「官方」「客服中心」「系统通知」却不说是哪家，可疑。
- 名字对不上：短信说「您孩子的学校」，落款却是别的名字，可疑。

### 第二看：让你做什么

垃圾短信绕来绕去，最后总要你做一件事。记住，**下面这四种要求，一个都不能答应**：

1. **点链接**——「点击链接领取补贴 / 查看包裹 / 确认订单」，链接基本是假网站，专门骗账号密码。
2. **报验证码**——「把收到的验证码发给我们」，验证码就是钱，谁问都不给。这条跟上一篇防骗那篇是同一条红线。
3. **先交钱 / 先垫付**——「中奖了先交手续费」「账户异常先转账保住资金」，先交钱的一律是骗。
4. **回拨陌生号码**——「回拨这个电话详询」，一回拨就中了吸费或套话的圈套。

### 第三看：是不是「刚好戳中你」

骗子会挑长辈最在意的事下钩：孙子上学、养老金、医保、快递、中奖。凡是**语气特别急、催你马上办、说过期作废、说别告诉别人**的，越急越假。真有事，银行和医院会让你去柜台、打官方电话，不会在短信里催你点链接。

> 一句口诀交给爸妈：**「中奖、补贴、快递异常、验证码——这四类短信，看一眼就删，不点、不回、不填。」**

### 把三看法写成一张小卡片

如果爸妈记不住，把下面这段抄在纸上、字号放大，压在手机下面。来一条短信，照着对一遍：

```text
短信三看法——看一样不对就删，别点别回

【第一看】谁发的？
  陌生长号码、含糊落款、名字对不上 → 可疑

【第二看】让你做什么？
  点链接 / 报验证码 / 先交钱 / 回拨电话
  → 四样里占一样，一律不干

【第三看】是不是催得特别急？
  中奖、补贴、快递异常、过期作废、别告诉别人
  → 越急越假

【记住四类】中奖 / 补贴 / 快递异常 / 验证码
  看一眼，删掉，不点、不回、不填。
```

### ⚠️ 认短信：这些千万别点

把下面这段念给爸妈，凡是看到这些，手指头先收回来：

- **别点短信里的链接**——哪怕写得像银行、像快递、像医院。要看，就让家里人帮着在浏览器里手打官方地址，别点短信给的。
- **别把验证码告诉任何人**——包括自称「客服」「警察」「银行工作人员」的。真工作人员不会要你的验证码。
- **别「先交钱再领奖 / 先垫付再退款」**——钱一转出去就要不回来了。
- **别回拨短信里的陌生号码**——要核实，用你自己存的官方电话打，别用对方给的号码。
- **别按短信提示「下载一个 App / 打开屏幕共享」**——这是近两年最常见的骗法，装了、开了，对方能看见你手机上的一切，包括密码和余额。

## 二、开骚扰拦截：花十分钟设一次，清净好几个月

认短信是防「进来」，开骚扰拦截是主动「挡在门外」。这件事的价值在于：**设一次就长期有效**，不用爸妈天天跟推销电话斗智斗勇。找个你在家的时间，照下面挑一条路走完。

### 先弄明白：拦的到底是哪种

骚扰电话主要两类：一是**推销、贷款、装修**这类营销电话，二是**响一声就挂、录音机器人**这类诈骗电话。手机自带的拦截功能两类都能挡个八九成。别指望一个都接不到，能做到「一天最多一两个漏网的」就算成功。

### 路一：用手机自带的骚扰拦截（最省事，优先选）

现在的国产手机基本都自带拦截，只是藏得深。帮你找出来、设好，一次到位。

1. 打开**「电话」**这个 App（就是平时打电话那个绿色图标），别进「设置」乱找。
2. 在电话 App 里找**「骚扰拦截」或「拦截记录」**——一般在右下角「更多」、右上角三个点，或者长按通话记录里某个号码弹出的菜单里。找不到，就在手机「设置」顶上的搜索框里输入「骚扰」两个字，它会直接跳出来。
3. 点开后，把**「拦截骚扰电话」「拦截营销电话 / 推销电话」**这两个开关都打开。有的手机叫「智能拦截」「陌生号码拦截」，看到类似的就打开。
4. 如果里面有**「拦截规则 / 拦截等级」**，选「中」或「标准」就够了——选太高，连快递、外卖的正常电话也挡了。
5. 有的手机还能拦**骚扰短信**，在同一个页面里找「短信拦截」，一并打开。
6. 设完，翻一下「拦截记录」，看看有没有已经拦下来的号码。有，说明生效了。

> 不同牌子按钮名字不一样：华为多在「电话 → 骚扰拦截」，小米多在「电话 → 骚扰拦截 / 设置 → 骚扰拦截」，苹果没有自带短信级拦截，但可以往下看「路三」。找不到就用设置里的搜索框搜「骚扰」，最省事。

### 路二：找运营商免费开通（不挑手机品牌）

不管用的是哪家运营商，都有免费的防骚扰服务，不用装软件、不花钱。让你或孩子用手机自带的客服 App，或者直接打运营商的官方客服电话，问一句「怎么开通免费的骚扰电话拦截」，按客服说的办一次就行。

- 好处：在运营商那一端就拦了，不占手机性能，老人不用管。
- 注意：**只认官方客服 App 和官方客服电话**，别信短信里发来的「开通防骚扰」链接，那本身就是骗局。

### 路三：苹果手机这样设（安静模式）

苹果没有国产手机那种「骚扰拦截」总开关，但有个「静音未知来电」很好用：

1. 打开**「设置」→「电话」**。
2. 找到**「静音未知来电」**，把开关打开。
3. 效果：不在通讯录里的号码打进来，手机不响、直接进语音留言，你自己手机上能看到未接来电。

> 提醒一句：开了这个，**快递、外卖、医院用陌生号码打来也会静音**。所以教爸妈养成一个习惯——打完电话回过头看一眼未接来电，重要的回拨过去。这条要讲清楚，不然容易漏事。

### ⚠️ 骚扰拦截：这些别乱设

- **别把拦截等级调到最高**——正常电话也打不进来，快递、社区、医院的电话可能被挡，因小失大。
- **别为了拦骚扰，去装不明来源的「拦截大师」类软件**——正经功能手机自带就够了，来路不明的软件本身可能就是广告和木马。
- **别信「付费解除拦截 / 付费增强拦截」**——官方的拦截免费，要你付费的多半是坑。
- **别把「紧急联系人 / 家人号码」设进拦截名单**——手一滑把家里人加进去，真有事打不进来就麻烦了。设完让爸妈拿家里人的电话试打一次，确认能接通。

## 三、腾出存储：先搞清是什么把手机塞满的

存储满了，手机就卡、微信发不出图、拍照提示「空间不足」。长辈的第一反应往往是「手机不行了要换」，其实大多数时候清一清就能缓过来。**关键是别乱删——先删最没用的，照片和聊天记录最后动。**

### 第一步：先看空间被谁占了

打开「设置 → 存储」（有的在「设置 → 通用 → 存储空间」），等它转几秒，会列出一个排行：哪个 App 占得最多，一目了然。念给爸妈听，让他明白「不是手机坏了，是这几样东西太多了」。

通常排前几名的就那几样：**微信、短视频 App、相册、浏览器缓存**。接下来按这个顺序清，从最没用的开始。

### 第二步：按占空间大小，从大到小清

**先清缓存——删了不影响任何东西。** 缓存是软件临时存的文件，删掉它，下次打开软件会自动重新生成，照片、聊天记录一概不丢。

- 微信：「我 → 设置 → 通用 → 存储空间 → 清理缓存」，只点「清理缓存」，先别点「管理聊天记录」。
- 短视频、浏览器等：在各自的「设置 → 清除缓存」里清一遍。
- 这一步最安全，**清完通常就能腾出好几个 G**。

**再删不用的软件。** 翻一遍桌面，那些「装了从没打开过」的游戏、购物、工具软件，长按图标删掉。拿不准是不是有用的，问一句家里人再删。

**然后处理微信里的视频和图片。** 微信占空间，多半是群里的视频、反复转发的图片堆出来的。在「存储空间 → 管理聊天记录」里，挑那些**不重要的群**清理，别动家人和重要联系人的对话。这一步要陪着做，让爸妈自己确认哪些群不重要。

**最后才是相册。** 相册怎么清，上一篇已经专门讲过——先备份、再删、留「最近删除」30 天后悔药，这里不重复。记住顺序：**缓存 → 闲置软件 → 微信文件 → 相册**，越往后越慢、越要小心。

### 第三步：留一成余量

清完别把空间塞得满满当当。留大约**一成空间空着**，手机运行才顺。往后每月帮爸妈清一次缓存，就不会再卡到打不开微信。

### ⚠️ 清存储：这些千万别点

- **别点弹窗里的「一键加速 / 一键清理 / 手机内存不足」**——尤其是清理软件弹出来的，它分不清哪张是垃圾、哪张是孙子的照片。看到就退出来。
- **别在「存储空间」里点「清空 / 恢复出厂」**——那不是清缓存，是把整个手机清空，照片全没。看清按钮再点，拿不准就别点。
- **别删微信聊天记录图省事**——聊天记录里可能有重要的地址、号码、凭证，删了找不回。只清缓存和明确不重要的群。
- **别为了腾空间去删「系统文件 / 不认识的文件」**——手机自己都搞不清哪些是系统文件，让长辈别碰。存储不够，清缓存和软件就够了。
- **别用「清理大师」类软件反复扫描**——扫出一堆「垃圾」吓唬人，诱导你付费、装软件。系统自带的清理够用了。

## 五、出错了怎么办

万一还是点错了、清错了，别慌，按顺序补救：

- **点开了垃圾短信链接**：立刻退出，别填任何东西、别下载任何东西。如果已经填了账号密码，马上用另一台设备改密码；如果转了钱，第一时间打官方客服电话挂失、并报警。越快越好。
- **把验证码说出去了**：马上联系对应机构冻结账户、改密码。记住，验证码一旦给出，就当密码已经泄露处理，别抱侥幸。
- **骚扰电话越拦越多**：说明拦截等级可能太低，或者号码被卖给了更多推销方。把拦截等级调到「中」，再帮他把号码加进运营商的免费防骚扰名单。
- **清缓存后手机还是卡**：再看一眼「存储」排行，如果微信还占着大头，按第三节处理微信里的视频和图片；还不行，可能真是手机老了，那时候再考虑换，别被「一键清理」忽悠着乱删。
- **误删了照片或聊天记录**：照片去「最近删除」找，30 天内能恢复；聊天记录如果之前没备份，基本找不回——这就是为什么第三节强调「聊天记录最后动、慢慢动」。
