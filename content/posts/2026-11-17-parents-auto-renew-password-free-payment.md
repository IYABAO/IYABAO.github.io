> 写给同辈的一句话：爸妈不是不舍得花钱，是根本不知道钱被扣了。自动续费藏在会员里，免密支付藏在付款码后面，扣款短信又被当成垃圾消息划掉。等你发现，可能已经悄悄扣了一年。今天这篇不讲道理，只给四条能照着点的路径——花五分钟，把这个口子堵上。

## 结论先放前面

手机里会偷偷扣钱的地方，就两个，记住名字就够了：

- **自动续费**：视频会员、网盘、音乐、云存储这些，首月几毛钱，到期自动按月/按年扣。关掉它，以后不再续。
- **免密支付**：不用输密码、不用按指纹就扣款的授权，常见于停车、共享单车、外卖、小程序。它本身不是扣钱，是**把门开着**，谁拿到手机都能划走钱。

**一句话记法：自动续费是"每个月都在扣"，免密支付是"不用问你就扣"。两个都要关。**

给爸妈的一句话版本：

> 手机里有两个开关，一个管"会员到期自动扣"，一个管"不用密码就扣"。今天让孩子陪着，把它们全关掉。

## 一、先把两件事分清楚，别关错

很多人一看"扣费"就慌，其实两者的处理动作不一样：

| 名称 | 它是什么 | 典型场景 | 要做什么 |
|---|---|---|---|
| 自动续费 | 到期自动扣下一期的钱 | 视频会员、网盘、音乐会员 | 取消"续订"，本期用完不扣下期 |
| 免密支付 / 自动扣款 | 授权后不用输密码就划钱 | 停车、单车、外卖、小程序、苹果生态 | 关掉授权，或把限额调低 |

有个容易混的点：**在苹果手机上买的会员，不是在微信或支付宝里关的**。很多人跑去微信里翻半天找不到，因为它是 Apple 扣的，得回 iPhone 的"订阅"里关。下面分四条路径讲，照着自己的手机挑一条走。

## 二、iPhone：在"设置"里关自动续费

苹果手机所有通过 App Store 开的会员，都集中在同一个地方管。一步步点：

```text
1. 打开「设置」
2. 点最上面自己的头像（Apple ID）
3. 点「订阅」
4. 列表里会列出所有正在续费的会员，一个个点进去
5. 点「取消订阅」→「确认」
```

几个提醒：

- 列表里可能有没有印象的会员——**只要不认识，直接取消**，反正也不影响别的。
- 取消后**本期已经付的钱不退，但到期不再扣**，这是正常的。
- 如果"订阅"里空空的，但还在扣钱，那多半是在微信或支付宝里开的，往下看第四、第五节。
- 关完订阅，顺手把免密也检查一下：

```text
设置 → 头像 → 「付款与配送」→ 查看绑定的支付方式
不需要的银行卡可以解绑，减少被扣的口子
```

## 三、安卓手机：在应用商店和 App 里关

安卓品牌多，但路子大同小异，认准两个入口：**应用商店的"订阅"** 和 **App 内部的"管理订阅"**。

主流品牌的订阅入口：

| 品牌 | 订阅入口 |
|---|---|
| 华为 | 应用市场 → 我的 → 订阅 |
| 小米 | 应用商店 → 我的 → 订阅 |
| OPPO | 软件商店 → 我的 → 订阅 |
| vivo | 应用商店 → 我的 → 订阅 |
| 腾讯应用宝 | 我的 → 我的订单 → 订阅管理 |

操作步骤：

```text
1. 打开自己手机的应用商店
2. 进「我的」→ 找「订阅」（有的叫"订阅管理"）
3. 逐个点开，选「取消订阅」/「退订」
4. 商店里没有的，再进那个 App 本身：
   我的 → 设置 → 账号/会员中心 → 管理订阅 → 关闭自动续费
```

安卓上还有个特别要注意的：**很多扣款走的是短信代扣或话费代扣**，不在商店里。如果话费账单莫名高，去查：

```text
运营商 App（移动/联通/电信）→ 我的 → 已订业务/增值业务
看到不认识的订购业务，全部退订
```

## 四、微信：关掉自动扣费和免密支付

微信是爸妈用得最多的，也是扣款最集中的地方。两个开关挨在一起，一次关完。

```text
1. 打开微信 → 「我」→「服务」→「钱包」
2. 点右下角「支付设置」
3. 里面有「免密支付」和「自动续费」两项（有的版本合在一起叫"免密支付/自动扣费"）
4. 点进去，会列出所有已授权的项目
5. 不认识的、不用的，逐个点「关闭扣费服务」/「解除授权」
```

关的时候按这个优先级来：

1. **完全不认识的**——直接关，不用犹豫。
2. **早就不用的**——比如几年前为了看一部剧开的会员，关掉。
3. **还在用的**——如果只是想省钱，可以考虑换成按月付、或者家里合用一个，但至少要知道它在扣。

顺带再做两件事：

```text
关掉"付款码免密"：
我 → 服务 → 付款码 → 右上角「…」→ 关闭"免密支付"

调低或关闭转账额度：
我 → 服务 → 钱包 → 安全保障 → 安全锁
开启后进入付款码/转账要多验一次，老人家反而更安全
```

## 五、支付宝：关掉免密支付和自动扣款

支付宝的入口也很集中：

```text
1. 打开支付宝 →「我的」→ 右上角「设置」
2. 点「支付设置」
3. 点「免密支付 / 自动扣款」
4. 列表里是所有签约的项目，逐个点进去
5. 选「关闭服务」/「解除授权」
```

同样，不认识的一律关。支付宝里还有个"小额免密"，金额不大但胜在频繁，建议直接关：

```text
支付设置 → 小额免密支付 → 关闭
```

如果爸妈用的是**花呗自动还款**，这个别关——它是还钱用的，不是扣钱坑人的。区分清楚：我们要关的是"签约扣款"，不是"自动还款"。

## 六、给子女的一张检查清单

别指望爸妈自己翻——这套路径对六十岁以上的人不友好，最好的办法是子女拿着他手机，按清单五分钟走一遍。建议收藏这张表，回家照着做：

```text
□ iPhone：设置 → 头像 → 订阅 → 逐个取消
□ 安卓：应用商店 → 我的 → 订阅 → 逐个取消
□ 微信：我 → 服务 → 钱包 → 支付设置 → 免密/自动续费 → 逐个关闭
□ 微信：付款码 → … → 关闭免密支付
□ 支付宝：我的 → 设置 → 支付设置 → 免密支付/自动扣款 → 逐个关闭
□ 支付宝：支付设置 → 小额免密支付 → 关闭
□ 运营商 App → 已订业务 → 退订不认识的增值业务
□ 翻一遍最近三个月账单，看有没有不认识的扣款
```

最后一条最关键：**关掉开关只是止血，翻账单才是查伤**。花三分钟翻一下微信和支付宝的账单明细，很多"每年都在扣"的项目，就是这么被发现的。

## 七、已经是被扣了好久，能要回来吗

能试，但别抱太大期望，越早越好：

- **刚扣几天**：直接找对应平台的客服申请退款，说明"老人误操作、未使用"，部分平台会退当期。
- **扣了几个月到一年**：打平台客服电话，态度客气但坚持，说明是未成年/老人不知情开通，有机会退部分。
- **完全不认可的代扣**：向支付平台投诉，或打 12315 消费者热线。
- **金额大、涉嫌诱导**：保留开通记录、扣款短信，必要时投诉到监管部门。

比追回钱更重要的，是**把开关关掉**——不然退款到账的当月，下个月又扣走了。

## 八、防在平时，三件事就够

1. **给爸妈的手机开"密码锁 + 指纹"**，别用"滑动解锁"，也别把密码写在纸上贴手机壳里。
2. **微信、支付宝都开"安全锁"**，进付款码、转账多验一次，老人家嫌麻烦，但正是这一下挡住误操作。
3. **每月陪爸妈看一次账单**，五分钟，重点看"自动扣款"这一类。养成习惯，比装十个 App 都管用。

还有一句要说给子女：**别用"你怎么这么傻，这都被扣钱"开头。** 爸妈不是傻，是这套设计本来就冲着让人看不见去做。你越怪他，他越不敢让你碰手机，下次扣得更多。坐下来，拿着手机一起点，是最好的方式。

---

最后一句：自动续费和免密支付本身不是坏东西，用好了很方便。问题在于**爸妈根本不知道自己开了**。今天花五分钟，把家里的手机都过一遍这张清单——堵住口子，比事后追钱省心得多。
